# Frozen-model inference and nested model selection

These files illustrate the input schema. They are not experimentally verified formulations or evidence that the requested properties are attainable. Replace the ingredient identities and specifications with the intended materials. An ingredient absent from a training catalog remains in a forward request, with catalog support reported explicitly.

Run commands from the repository root with the project environment. Every output below must be a new path. Input files can contain a JSON object, a JSON array of objects, or JSONL. A `propose` input must contain exactly one request, so `--count` is the complete proposal budget.

## Neural forward prediction

`NEURAL_PAIR_DIR` must contain the matching `forward.pt`, `inverse.pt`, `features.json`, and `checkpoint_manifest.json` produced by this training workflow. If forward and inverse configurations differ, select the directory appropriate to the requested direction.

```bash
PYTHONPATH=src .venv/bin/python -m coarsepgnn_retrain predict \
  --family neural --model-dir "$NEURAL_PAIR_DIR" \
  --input examples/retrain/forward_request.json \
  --output outputs/inference/neural_forward.json --device cpu
```

Do not provide a measured `value` in a forward prediction request. The returned prediction is in the original normalized dataset unit: degrees Celsius for Tg/Tm, MPa for ultimate tensile strength, and percent for elongation at break. Auxiliary tasks retain their dataset-unit semantics. Unknown tasks are returned as `unsupported`, without removing the request.

## Classical deployment model

The following command performs a **new full-data classical refit**, so it belongs to an authorized training workflow. It selects its configuration from previously stored inner-validation scores, without reading outer-test errors. The resulting model has no additional independent test of its own.

```bash
PYTHONPATH=src .venv/bin/python -m coarsepgnn_retrain baseline-refit \
  --dataset "$DATASET_JSONL" --splits "$SPLITS_JSON" \
  --baseline-run "$BASELINE_RUN_DIR" \
  --output outputs/deployment/classical --seed 20261117 --max-seconds 14400
```

Prediction then uses the deployment directory's manifest, feature state, and joblib models:

```bash
PYTHONPATH=src .venv/bin/python -m coarsepgnn_retrain predict \
  --family classical --model-dir outputs/deployment/classical \
  --trusted-generated-artifact \
  --input examples/retrain/forward_request.json \
  --output outputs/inference/classical_forward.json
```

Use `--trusted-generated-artifact` only for a model generated by your own verified workflow. Joblib uses pickle; a matching checksum alone does not make an unknown file safe to load.

## Inverse proposals

```bash
PYTHONPATH=src .venv/bin/python -m coarsepgnn_retrain propose \
  --model-dir "$INVERSE_PAIR_DIR" \
  --input examples/retrain/inverse_single_request.json \
  --count 20 --seed 20261117 \
  --output outputs/inference/inverse_single.json --device cpu
```

`--count` counts raw proposals, including duplicates. There is no hidden resampling, forward ranking, or additional fitting. The result includes catalog material identities and generated molecular mole fractions. Historical recipe ratios are not reused as generated ratios. Optional extender absence is reported as `NONE`.

The multiple-target example can be supplied to the same command. It returns `scope="compositional_query_unvalidated"`, because this model was not trained on jointly observed target states. All targets must share one condition mapping; separate protocols for separate properties are rejected. Every candidate retains `chemical_validation="not_performed"` and `experimental_success=null`.

## Forward-family selection from completed nested runs

```bash
PYTHONPATH=src .venv/bin/python -m coarsepgnn_retrain champion \
  --dataset "$DATASET_JSONL" --splits "$SPLITS_JSON" \
  --baseline-run "$BASELINE_RUN_DIR" --neural-run "$NEURAL_RUN_DIR" \
  --bootstrap-replicates 2000 --output outputs/selection/forward_family
```

Both runs must be complete, use the same dataset and splits, and satisfy the recorded input bindings. The neural run must have declared the forward-family selection policy before training. This command compares pooled inner-validation scores, preserves each neural inverse result, and uses outer predictions only for reporting. The single recorded baseline is reported once; reused baseline predictions are not counted as independent fits from multiple seeds. Outputs are `selection_lock.json`, `selected_oof.csv`, and `metrics.json`.
