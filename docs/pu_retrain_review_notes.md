# PU 全量训练入口的独立只读审查

审查日期：2026-11-17。本说明审查新流程的数据利用、划分和选择路径，不替代实际训练结果，不修改历史正式合同或将旧负结果改成成功。源码位置对应本轮待冻结的新包；数据、来源证据与实际核对回执另行绑定完整 SHA-256。

## 1. 可以依据当前数据和代码确认的事项

| 设计要求 | 已读实现位置 | 实际证据与边界 |
|---|---|---|

| 全部观察的 OOF 分母保留 | `training.py:468–472`；`metrics.py:26–65` | 每个种子要求共享监督集合恰好覆盖一次；目录外原料和不支持任务保留 ID 及覆盖率，不能当作恢复成功或删掉困难行 |

上述路径核对证明了代码中的数据流约束，不是对所有进程或所有外部读取的绝对证明。本流程没有历史正式运行那种操作系统级测试文件封存机制；研究人员还已经查看过旧 R10 结果，因此应保持回顾性评价表述。

## 2. 条件与数值字段审查

允许数值字段为测试温度、湿度、应变/横梁速度、升降温速率、频率、试样厚度和扫描/事件序号。允许类别字段为方法、标准、加载方式、气氛、试样几何、制样、调理、转变判据与相域；另外使用结构架构标签。`condition_raw`、`definition_raw`、`raw_records`、publication/family 元数据不作输入。

实际允许字段未发现直接目标数值/结果描述。字符串中出现的 `MPa` 为模压或热压制样压力，`fracture` 描述加载终点/状态，不能据这些词单独认定泄漏。Tg/Tm 观察中的测试温度字段与其目标相等的候选数为 0。全部字段及原文例子保存在 `outputs/retrain-20261117/field_audit.json`；三条 UTS 端点修复和来源元数据增强均已证明没有改变条件字段。

只读脚本 `scripts/audit_pu_retrain_inputs.py` 进一步比较了源无关配方、允许条件与任务签名。其固定文字哈希步骤与 `features.py` 白名单一致，不拟合中心/尺度或词表。旧划分中“配方 + 完整允许条件 + 任务”完全相同的跨折签名为 0；但两份文献可能用不同措辞、不同缺失程度重录同一实验，因此这不能抵消已经确认的专利家族隔离缺口。

## 3. 实际发现并修复的隔离缺口

旧 200 闭包方案在已有键上跨折重合为 0，新增来源审查却确认三个家族跨折：美国 continuation 家族 42102758（62 行）、中国同申请公开/授权家族 80233289（26 行）、中美 PCT 家族 83916461（36 行）。这些关系来自出版物身份和原申请关系，不依赖性质值相等。旧模型结果不能称最终未见来源结果。

完整 56 专利扫描有 54 个目标 Family ID 已核读；US3746665A、CN118165222A 明确 unresolved。相同可观测配方还被新划分保守地整体分组。源无关配方键的含义是“在已记录结构、规格、比例上相同”，不等于完整化学物质、加工历史和真实实验均已证明相同。它不用于删除记录，也不以性质标签决定。真实母表的 v3 分组只读构建及验证得到 173 个闭包、最大 603 行，5 个外层测试集合含 775/795/774/772/856 条监督观察，5×3 内外分组验证通过；这个预检查不等于训练已经完成。

全部 4218 行的实际 `tensor_hash` 有值数量是 **0**；原图散列仅作谱系辅助，新模型本身使用原料指纹和配比。因此目前没有“全部模型输入张量去重后零跨折重合”的实际证据。最终可验证的是已记录来源、核实家族、材料、配方、原图、谱系和新定义可观测配方身份的闭包隔离。两项未解析家族、原始提取错误与未记录化学细节仍构成限定。

记录保留数量是来源可追溯的观察条目数，不能直接当作相同数量的独立物理实验。经确认同族的条目仍全部保留和同折；是否代表同实施例的重复提取，需要进一步原文判定，当前没有按相同数值猜测删除。

## 4. 评价结论必须保留的范围

1. **回顾性评价。** 新外折样本不用于对应模型拟合或内层选择，但研究者知道旧实验的总体结果；不能宣传新盲测。
2. **逆向目录支持范围。** `evaluate_models` 的逆向组合损失只在完整训练目录可支持的记录上形成选择分数，同时给出全部分母、目录外 ID 和覆盖率。不能将这个条件性损失当作全化学空间的性能。
3. **真实组分数指标有 oracle 信息。** `training.py:157–170` 的 `component_set_at_true_count` 使用真实组分数决定 top-k。其用途是诊断给定组分数时的集合恢复，不是自由生成 Hit@20，也不是实验性质成功率。
4. **区间条件于既有模型。** `metrics.py:11–23` 以完整来源闭包重采样存储的 OOF 误差，没有重跑拟合/配置选择，因此不是包含全部训练不确定性的区间。
5. **稀有辅助任务。** 两条结晶温度来自单一闭包。若该闭包被留出，训练侧无该任务数值；应报告不支持和覆盖率，不能补零误差或伪造跨来源区间。
6. **模型与任务范围。** 当前是多组分指纹集合网络，不是已经运行的旧 CoarsePGNN 图主干/语言模型。逆向训练主要使用单性质原子观察；多目标接口能力不等于已经取得共同状态的四性质联合实测泛化证据。
7. **候选合法性。** 比例归一化和角色上限不能代替全面的官能度计量、反应图及合成可行性验证。无新实验时只能报告计算预测。
8. **全量部署拟合与评价分开。** 全3972观察拟合出的部署权重用于预测服务；其母表内拟合表现不能代替折外评价。部署配置仍必须按预先固定的内层汇总规则选择。
