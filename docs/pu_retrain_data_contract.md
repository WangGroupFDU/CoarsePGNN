# PU 全量可追溯数据：数据与评价原则

版本日期：2026-11-17。本文描述新训练流程的数据口径、监督方式与评价边界，不报告尚在执行的训练性能，也不改写历史正式实验的合同、结果或结论。

本流程同时遵守两项原则：**利用全部已取得、可追溯的实验观察；用未参与对应模型训练的样本评价泛化能力。**“全量”约束数据利用，“留出”约束性能结论；二者通过分组嵌套交叉验证与后续全量部署拟合分别落实。

## 1. 本次取得的数据范围

数据入口为公开发布的 `CoarsePGNN_pu_v1.0.1.zip` 内完整 `pu/dataset_manifest.csv`，结合其 `provenance/measurements.csv`、`provenance/test_campaigns.csv` 与历史归档的 Tg 原子成员谱系、训练证据。公开母表的 3657 行全部进入新入口，没有按旧 `APPROVED_PRIMARY`、完整测试条件、单一 D/P/E 或“完整四性质样本”筛选。

当前取得的是**完整公开 PU 入口及可追溯补充关系表**。原始完整 SQLite 未包含在本次可用输入中，因此不能将“已使用全部公开输入”表述为“原始数据库已穷尽”。入口也支持读取补充 SQLite 的完整 `measurements` 表；未来取得新增来源时，应建立独立的数据版本和评价记录，不能直接把新增信息补入已经产生评价结果的冻结数据版本。

## 2. 四个主要任务与辅助任务

全部共同监督记录都进入正向和逆向模型；不同物理端点保持不同任务身份。不能通过将未明确的强度端点改名为 UTS，或把一般热事件改名为熔融温度，来增加主任务标签数。

|---|---:|---|
| 玻璃化转变温度 Tg | 1118 | 主要任务，保留 DSC/DMA 等方法、判据及相域身份 |
| 熔融温度 Tm | 713 | 主要任务 |
| 极限拉伸强度 UTS | 475 | 主要任务，现有来源元数据支持该端点 |
| 断裂伸长率 | 1032 | 主要任务 |
| 端点未明确的拉伸强度 | 393 | 辅助任务，保留强度数值及端点不确定性 |
| 一般热事件 | 239 | 辅助任务，包括未明确为熔融的热代理或解离事件 |
| 结晶温度 | 2 | 独立辅助任务，不能作为 Tm 标签 |

按宽泛性质族归类时，Tg/Tm/强度/伸长分别有 1118/954/868/1032 条；按主任务端点归类时，主要四任务共 3338 条，其余 634 条仍提供辅助监督。两种统计口径必须同时说明，不能把辅助标签数从数据利用总量中隐去，也不能混入主要端点性能。

### 2.1 强度端点识别的三条修正

公开母表有 693 条类型标为 `tensile_strength_ultimate`，另有 175 条类型为 `tensile_strength_unspecified`。初次新入口曾将 693 条分为 472 条主 UTS 和 221 条辅助强度。逐条核查这 221 条的 45 组原始定义后，确认：

- 176 条有明确的端点歧义说明，其中 134 条同时带有历史明确歧义理由；
- 42 条在当前可用元数据中缺少明确端点正证据；这表示“尚不能确认”，不表示“已经证明不是 UTS”；
- 3 条明确写为 `maximum tensile strength described in the text`，是通用正则漏识别，应该归入主 UTS。

这三条观察为 `MEA_10a1bb5dfc9cb8d51cc6`、`MEA_21ce5d7a7239c5318877` 和 `MEA_4270fe25af9d178cbbc3`，共同来源为 `SRC_dc642bae4084c5e80698`。修复扩展了明确“maximum tensile strength”端点的通用识别规则，不以 ID 特判。明确的歧义措辞仍具有优先级。

修复后主 UTS 为 475，辅助强度为 393；全部 4218 个保留 ID 和 3972 个共同监督 ID 不变。逐字段比较只有三条记录的 `target` 与 `issues` 改变，原始记录、数值、配方和条件不变。差异回执为 `outputs/pu-all-data-20261117/endpoint_correction_receipt.json`。这些主/辅助任务是基于当前来源元数据的可追溯语义分类，不替代对全部原始论文逐项重新裁定。

## 3. 为什么保留均值父记录，却不重复训练它们

246 个 Tg 聚合父记录的公开原文中明确列出了 561 个成员的测量 ID、类型和数值。新入口从这些明确列表恢复原子观察，并结合已有成员谱系恢复可追溯协议。若原子成员已经独立存在，则链接已有记录，避免再次计数。

父均值由其子观察计算而来。如果同时把父均值和全部子观察视为独立实验监督，相同实验信息会重复计权；若父子进入不同数据分区，还会造成直接泄漏。因此父记录继续完整保留于母表，参与来源闭包构建，但不参与独立监督损失。这个处理消除了重复证据，不是删除原始实验。

恢复数值只接受明确成员列表，不通过均值逆推出未知成员。成员缺少原协议时，条件显式标为未知；不能把父记录混合后的方法、相态或平均条件复制成成员的真实测试条件。已知 Tg 判据从原字段和明确的来源类型恢复，不因统一任务名而抹去。

实现入口为 [`dataset.py`](../src/coarsepgnn_retrain/dataset.py) 的 `build_dataset`、`normalize_record` 与成员恢复逻辑；已知答案测试位于 [`test_retrain_dataset.py`](../tests/test_retrain_dataset.py)。

## 4. 保留全部字段，按可观测项监督

每条记录保留原始字段副本、输入文件与行号、SHA-256、观察/材料/来源/配方身份、原料规格、连续配比、测试条件、标签来源类型和父子谱系。无值的字段显式保留缺失状态；母表保留字段不等于允许模型使用所有字段。

正向模型只在真实可观测的性质标签上计算损失。逆向模型在可辨原料身份上计算组分监督，在已知正配比上计算比例监督。部分配比不自动补成完整配方；未报告 Mn 不用伪造的数值参与计量换算。若某条未来补入记录完全缺少性质数值、可辨配方或来源关联，仍保留该行及具体原因，但不能宣称它提供了不存在的监督。

当前这 3972 条共同观察的结构核验结果为：有限性质值、正向 mask、逆向组分 mask 和配比 mask 均为 3972/3972；每条均有至少两个不同目录身份的正投料组分，所以具有实际比例监督的自由度。当前数据没有部分配比的共同监督记录，代码仍支持这种输入。

### 4.1 条件输入防止结果泄漏

[`features.py`](../src/coarsepgnn_retrain/features.py) 仅使用显式允许的结构化条件。数值条件包括测试温度、湿度、速率、频率和试样厚度等；类别条件包括方法、标准、加载方式、试样几何、制样与调理、转变判据和相域。自由原文 `condition_raw`、`definition_raw`、`raw_records` 以及来源/材料/配方 ID 不作为模型条件特征。

对当前母表的允许字段检查未发现直接目标数值或结果描述进入特征。允许文本中的 `MPa` 描述模压/热压压力，`fracture` 描述加载终点或样品状态，不能仅凭单位或单词出现就误删真实条件。检查清单、字段覆盖率和原始例子保存在 `outputs/retrain-20261117/field_audit.json`；它针对三条端点修正前的母表，但修正未改变任何条件字段。这是有明确字段范围的审查，不是对全部文献提取准确性的无限保证。

所有需要拟合的缺失值填补、尺度、目标变换、原料目录只在当前训练折建立。固定分子指纹和固定文本哈希不使用性质标签拟合词表。外层留出集出现训练目录外原料时，应保留其预测与支持范围标记，报告未知原料覆盖率；不能悄悄删除困难样本来提高逆向性能。

## 5. 正向和逆向共享训练观察

[`training.py`](../src/coarsepgnn_retrain/training.py) 的 `fit_pair` 接收一个共同的 `train_rows` 集合，同时构建两个方向的训练批次。每个仍在训练的方向，其每个 epoch 都遍历全部共同观察一次，并保存覆盖数量、唯一 ID 数和 ID 散列；发现遗漏、重复或逆向记录无实际监督即报错。

两个方向可以依据各自的内层验证指标选择不同训练 epoch 数，因为收敛速度可能不同；这不改变其使用的观察 ID 集合。早停后的方向不会继续优化，但不能把“少训练了若干 epoch”表述成“使用了更少实验记录”。辅助任务可以具有较小、固定的正权重，材料和任务也可以等权平衡；这调整重复测量的贡献，不移除任何已取得的有效观察。

不得要求一条记录同时具备全部四性质才能训练逆向模型。单性质和已核实共同状态的多性质输入应分别保留观测 mask，不能把不同样品或不同状态的性质拼成虚构的四性质实测标签。

## 6. 未参与训练样本上的评价

最终划分对全部 4218 条保留记录构建来源身份传递闭包，并整组进入同一分区。关联包括共享来源、规范化 DOI/专利公开根、已核实专利家族、材料、配方、原图、父子谱系及源无关可观测配方身份。保留记录的条件和性质数值不用于判定同族，数值相同也不用于删行。不同来源 ID 本身不保证统计独立。

原有 200 闭包诊断被发现遗漏三组跨源专利家族：`US8962785B2 / US9574043B2`、`CN114057971A / CN114057971B` 和 `US20250250389A1 / CN115322330B`。它们在旧划分中分别涉及 62、26、36 条记录，确实横跨外折。旧结果保留为隔离不足的诊断产物，不能用作最终未见来源泛化结果。新划分修复来源关系，再按同一模型候选和训练政策重新运行；不能挑选旧划分或新划分中较好的一套性能。

针对 202 个来源的完整书目核对中，56 个专利全部进行了家族查询，54 个取得目标页面明确 Family ID。`US3746665A` 和 `CN118165222A` 的家族元数据在本次有界检索中无法获取，映射内明确标为 `family_unresolved`，所有记录仍保留。不能把这两项说成已证实的单成员家族，也不能据其他专利的引用页面推定其家族。最终已知家族关系的隔离可以验证，但“全部潜在跨文献复录均已排除”仍无充分证据。具体映射为 `configs/retrain/pu_source_family_keys.json`，证据与可复现编译入口见 `docs/pu_retrain_source_family_audit.md`。

采用 **5 折外层 × 3 折内层**的分组嵌套交叉验证，固定初始划分种子 `20261117`。实际划分由 [`splits.py`](../src/coarsepgnn_retrain/splits.py) 生成和复核，禁止因闭包不平衡而拆组或删行。

1. 外层每次完整留出一组闭包，仅用于该外层模型的最终评价。每个共同监督观察恰好获得一次外层留出预测。
2. 外层训练部分内部再分三折，用于候选配置、预处理选择与训练 epoch 数选择。
3. 选择后仅在该外层训练部分重新拟合，使用内层已确定的 epoch 数；外层测试标签不参与早停、调参或种子选择。
4. 全部基线和模型使用同一外层划分与相同目标口径。主要四性质分别报告；辅助任务和未支持任务单独呈现，不把其缺失性能填成零误差。
5. 汇总 OOF 预测时按材料和来源闭包描述样本量，给出跨来源不确定性。只来自一个闭包的任务没有可支撑跨来源泛化的重复单元；本数据中的两条结晶温度观察正属此类，不能用普通逐行置信区间掩盖这个限制。

只有嵌套评价完成后，才可依据预先规定的内层选择汇总规则，在全部 3972 条共同观察上拟合部署模型。这个全量模型用于后续实际预测；它在同一母表上的拟合结果不能替代 OOF 泛化结果。

### 6.1 历史测试已经被查看

历史 R10 已经打开过其测试窗口，历史失败和负结果仍有效。因此本次工作应称为 **retrospective grouped cross-validation（回顾性分组交叉验证）**，而不是对完全未知数据的新盲测。重新训练不复用历史监督权重，各外折预测在计算上来自未训练该折记录的模型；但研究人员已经了解历史总体表现，这种知识不能通过重新随机划分消除。

将来需要更强的外部验证时，应使用此研究设计确定后新取得、此前未看过的独立来源或新实验。当前工作不把新实验列为实施完成的前提，也不伪称已有该类证据。
